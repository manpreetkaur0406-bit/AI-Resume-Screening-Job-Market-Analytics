
# 🤖 AI Resume Screening & Job Market Analytics

## 📌 Description
AI Resume Screening & Job Market Analytics is a data analytics and machine learning project that helps users analyze resumes, calculate ATS scores, identify skill gaps, recommend suitable jobs, predict salaries, and explore job market trends through interactive dashboards.

## 🚀 Features
- 📄 Resume Analysis
- 🎯 ATS Score Calculator
- 🧠 Skill Gap Analysis
- 💼 Job Recommendation
- 📊 Salary Analytics Dashboard
- 💰 Salary Prediction (Machine Learning)
- 💡 Resume Improvement Suggestions

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Plotly
- Scikit-learn
- Joblib

## 📂 Datasets
- Resume Dataset
- Data Analyst Jobs Dataset
- Data Science Salary Dataset

## ▶️ Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
